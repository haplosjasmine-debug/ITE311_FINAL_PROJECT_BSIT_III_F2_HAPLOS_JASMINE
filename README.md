# PetBook: Pet Care Appointment Booking & Records System

**Student Name:** Haplos, Jasmine M
**Course and Section:** BSIT III - F2

## Project Description
A backend API for a web-based pet care system that handles online booking, SMS reminders, pet health records, and staff schedules. The system tracks a 10% commission on completed bookings for the developer.

## Technologies Used
- Node.js
- Express.js
- MySQL
- JWT
